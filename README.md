# Binance money trail

Public on-chain analysis of the Binance hack of 29 October 2026.

Open `index.html` with a double click or from any static server. `dashboard.html` is a self-contained NeoDash export with one page per transaction type. It needs an internet connection only for fonts. `nodes.json` and `edges.json` hold the movements grouped by wallet pair and asset.

Data cut: 2 November 2026. Figures can change. A flagged address does not prove who controls it. Attribution belongs to the cited sources.
